## 새 기능
- **사이트 차단**: 메인 창 → 사이트 차단에서 YouTube·Instagram 같은 사이트를 이 Mac의 모든 브라우저와 앱에서 막을 수 있습니다. 끔 / 항상 차단 / 시간표대로(요일·시간대, 자정 넘김 가능)를 고르고, 차단할 사이트를 직접 추가·삭제합니다. 처음 한 번 관리자 암호로 도우미를 설치하면 그 뒤로는 암호를 묻지 않습니다. 기본은 꺼져 있습니다.
- **자동 녹음할 프로그램 고르기**: 설정 → 녹음에서 통화 앱과 브라우저를 하나씩 켜고 끌 수 있습니다. 목록에 없는 통화 앱은 **앱 추가…**로 넣거나, 통화 중에 보이는 '지금 마이크를 쓰는 앱'에서 바로 추가합니다.
- **브라우저 회의 서비스**: 서비스마다 이름과 창 제목 단어(별명)를 여러 개 둘 수 있습니다 (예: Google Meet = "Google Meet", "Meet -"). 기본 서비스도 보이고 수정·끄기·삭제·복원할 수 있습니다. 이전 버전에서 추가한 회의 사이트 단어는 자동으로 옮겨집니다.

## 고친 점
- **컴퓨터 소리 녹음 방식을 바꿨습니다.** Mac 전화 앱(iPhone 통화)으로 받은 통화에서 상대방 목소리가 녹음되지 않던 문제 때문에, 컴퓨터 소리를 Core Audio에서 직접 받습니다. 처음 녹음할 때 '시스템 오디오 녹음' 권한을 물을 수 있습니다.
- 브라우저 통화를 자동 녹음하는 중에 다른 탭으로 옮기면 녹음이 멈추던 문제를 고쳤습니다. 이제 브라우저가 마이크를 쓰는 동안 계속 녹음합니다.
