## 새 기능
- **자동 업데이트**: 앞으로는 새 버전이 나오면 앱이 알려 주고 바로 설치합니다 (설정 → 업데이트에서 끄거나 지금 확인 가능).
- **시작 안내**: 처음 실행하면 필요한 권한과 선택 기능을 한 화면에서 설정합니다.

## 변경
- Caps Lock 한/영 전환과 통화 자동 녹음은 기본으로 꺼져 있습니다.

## 설치
0.1.0을 쓰고 있었다면 이번 한 번만 직접 받아서 응용 프로그램 폴더에 덮어쓰세요. 다음 버전부터는 자동으로 업데이트됩니다.
처음 열 때 "확인되지 않은 개발자" 창이 뜨면 "완료"를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"를 누르세요.
