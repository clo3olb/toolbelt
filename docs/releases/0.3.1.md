## 고친 점
- **클립보드 기록을 켜면 복사할 때마다 키체인 암호 창이 반복해서 뜨던 문제를 고쳤습니다.** 이제 키체인 대신 Mac의 보안 칩(Secure Enclave) 키로 암호화해서, 업데이트 후에도 창이 뜨지 않습니다. 비밀 항목은 보안 칩이 Touch ID나 Mac 암호 확인을 직접 요구합니다.
- 이전 버전의 클립보드 기록은 새 방식으로 옮길 수 없어 새로 시작합니다. 키체인 접근 앱의 "Toolbelt 클립보드" 항목은 더 이상 쓰지 않으니 지워도 됩니다.
- 클립보드 접근이 '항상 허용'이 아니면 기록하지 않고 안내만 표시합니다 (허용 창이 반복해서 뜨지 않도록).

## 새 기능
- **클립보드 창**: 메인 창 → 클립보드가 녹음처럼 목록과 상세로 바뀌었습니다. 검색, 더블클릭 복사, 비밀 항목은 인증 후 30초 동안 보기.
- **CPU 온도·팬**: 시스템에 온도계 게이지와 팬 속도, 발열 상태를 표시합니다.
- **회의 사이트 단어**: 설정 → 녹음에서 브라우저 회의 사이트를 추가해 통화 자동 녹음에 포함할 수 있습니다. 브라우저로 통화하는 동안 창 제목을 보여줘 어떤 단어를 넣을지 알 수 있습니다.
