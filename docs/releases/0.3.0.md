## 새 기능
- **클립보드 기록** (기본 꺼짐): 복사한 텍스트를 최근 200개, 7일 동안 이 Mac에만 암호화해 보관합니다. 팝오버나 메인 창 → 클립보드에서 눌러 다시 복사할 수 있습니다.
- **비밀 값 보호**: API 키·토큰·개인 키, 비밀번호 관리자에서 복사한 값은 키체인에만 저장하고 기록에는 가려서 보여줍니다. 다시 복사할 때 Touch ID나 Mac 암호를 확인하고 30초 뒤 클립보드에서 지웁니다.
- **비밀로 바꾸기**: 평범한 비밀번호가 기록에 남았다면 🔒 버튼으로 가릴 수 있고, 같은 값은 다음부터 처음부터 비밀로 저장합니다.

## 변경
- 설정 → 권한과 시작 안내에 클립보드 접근 권한을 추가했습니다.

## 처음 켤 때
macOS가 "다른 앱에서 붙여넣기"를 허용할지 묻습니다. 시스템 설정 → 개인정보 보호 및 보안에서 Toolbelt를 **항상 허용**으로 해 두면 다시 묻지 않습니다.
