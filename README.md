# Toolbelt

macOS 메뉴바 유틸리티 모음 — 녹음·전사, 통화 자동 녹음, 창 배치, 디스플레이 연결 해제, Caps Lock 한/영 전환, 시스템·저장 장치 사용량.
기능별로 `Sources/Toolbelt/<기능>/`에 분리한다.

## 설치 (사용자)

macOS 26 이상, Apple Silicon.

1. [Releases](../../releases)에서 `Toolbelt-<버전>.zip`을 받아 압축을 풀고 `Toolbelt.app`을 **응용 프로그램** 폴더로 옮긴다.
2. 처음 열면 "확인되지 않은 개발자" 경고가 뜬다 (Apple 공증을 받지 않은 앱이라서).
   **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의 **"그래도 열기"**를 누른 뒤 다시 연다. 버전마다 한 번.
3. 처음 실행하면 **시작 안내** 창이 뜬다. 쓰려는 기능에 필요한 권한만 허용한다 (설정 → 일반에서 다시 볼 수 있다).
   - **손쉬운 사용** — 창 배치, 브라우저 회의 감지
   - **마이크**, **화면 및 시스템 오디오 녹음** — 녹음 (화면 녹음 권한은 허용 후 앱을 다시 실행)
4. Caps Lock 한/영 전환과 통화 자동 녹음은 **기본으로 꺼져 있다** (키보드·녹음 동작을 바꾸므로). 시작 안내나 메인 창에서 켠다.
5. 메뉴바 🔧 → 아래 **설정**에서 로그인 시 자동 실행, 팝오버에 보일 기능과 순서를 고른다.

업데이트: 0.2.0부터 **자동 업데이트**(Sparkle). 새 버전이 나오면 앱이 알려 주고 설치까지 한다 (메인 창 → 설정 → 업데이트에서 끄기·지금 확인).
같은 인증서로 서명돼 있어 업데이트 후에도 권한은 유지된다. 0.1.0 사용자는 0.2.0을 한 번 직접 받아 덮어써야 한다.
녹음·전사는 모두 이 Mac 안에서 처리되고 외부로 보내지 않는다 (`~/Library/Application Support/Toolbelt/Recordings/`).

메뉴바의 🔧 아이콘을 누르면 팝오버 패널이 열린다 (`Sources/Toolbelt/Panel/`). 기본 순서는 녹음, 시스템, 창 배치, 디스플레이, 키보드.

**메인 창** (팝오버 오른쪽 위 창 버튼, 또는 ⌘,로 설정): 사이드바에서 기능별 상세 페이지와 설정을 연다 (`Sources/Toolbelt/MainWindow/`).
- 녹음: 녹음 막대 + 목록 + 재생·전사 / 시스템: 게이지·기준 / 창 배치: 버튼·단축키 표 / 디스플레이: 모니터·안전장치 / 키보드: 한/영 전환 상태
- **설정**: 팝오버에 보일 기능 켜고 끄기, 끌어서 순서 바꾸기, 로그인 시 자동 실행, 통화 자동 녹음, 녹음 폴더, 권한 상태
- 메인 창의 창 배치 버튼은 Toolbelt 직전에 쓰던 앱의 창에 적용된다.

## 기능

### 녹음 · 전사 (`Sources/Toolbelt/Recorder/`)

팝오버 → 녹음 → 빨간 버튼으로 시작/정지. 녹음 중에는 메뉴바 아이콘이 빨간 녹음 표시로 바뀌고, 팝오버를 닫아도 녹음은 계속된다.

**통화 자동 녹음** (팝오버 → 녹음 → 스위치, 기본 켜짐): 통화 앱이 마이크를 쓰기 시작하면(메뉴바 주황 점과 같은 정보) 자동으로 녹음한다.
- 대상: 전화(iPhone 통화를 Mac에서 받을 때), FaceTime, Slack, 카카오톡, WhatsApp (+ 설치 시 Zoom, Teams, Discord, Webex)
- 브라우저(Chrome, Arc, Safari, Edge, Whale)는 **창 제목**에 Meet·Zoom·Teams·Webex 등이 있을 때만 (손쉬운 사용 권한으로 읽음)
  - 메인 창 → 설정 → 녹음 → **브라우저 회의 서비스**: 서비스마다 이름과 창 제목 단어(별명)를 여러 개 둔다 (예: Google Meet = `Google Meet`, `Meet -`). 기본 서비스도 수정·끄기·삭제할 수 있고 '기본 서비스 복원'으로 되살린다.
  - 브라우저 녹음이 시작된 뒤에는 다른 탭으로 옮겨도 그 브라우저가 마이크를 쓰는 동안 계속 녹음한다.
  - 메인 창 → 설정 → 녹음 → **자동 녹음할 프로그램**에서 앱·브라우저별로 켜고 끈다 (기본은 모두 켜짐, 설치된 것만 표시). 목록에 없는 통화 앱은 **앱 추가…**로 넣거나, 그 앱으로 통화하는 중에 보이는 '지금 마이크를 쓰는 앱'에서 바로 추가한다.
    브라우저로 통화하는 동안 그 화면에 현재 창 제목들이 보이므로 어떤 단어를 넣을지 알 수 있다.
- 제외: ChatGPT·Claude 음성 대화, 음성 메모, 받아쓰기 등 목록에 없는 앱
- 3초 이상 마이크를 쓰면 시작, 5초 동안 안 쓰면 정지 (대기 중에는 메뉴바 아이콘이 주황 빈 원 ○, 팝오버에 "곧 자동 정지" 표시). 제목은 `카카오톡 통화 녹음 · 14:05` 형식으로 자동 지정
- 직접 시작한 녹음은 통화가 끝나도 멈추지 않는다. 이미 녹음 중이면 새로 시작하지 않는다.
- 대상 목록: `Sources/Toolbelt/Recorder/CallDetector.swift`의 `CallApps`. 마이크를 쓰는 프로세스는 로그로 남는다:
  `log show --last 1h --predicate 'process == "Toolbelt"' | grep 마이크`

**녹음 페이지** (메인 창 → 녹음, 팝오버의 "모든 녹음" 또는 녹음 행 버튼): 왼쪽 목록, 오른쪽 상세.
- 목록 위 녹음 막대: 녹음 시작/정지, 경과 시간, 통화 자동 녹음 스위치. 녹음을 시작하면 그 녹음이 선택돼 제목을 바로 적을 수 있다.
- 제목: 상세 맨 위를 클릭해 입력 (Enter 또는 포커스 이동 시 `meta.json`에 저장, 녹음 중에도 가능). 없으면 날짜로 표시. 폴더 이름은 날짜 그대로.
- 재생: 두 트랙을 시간 맞춰 함께 재생 (스페이스바 재생/일시정지)
- 전사 내역: **대화** 보기(시각·나/상대·문장, 시각을 누르면 그 지점부터 재생, 재생 중인 줄 강조) / **텍스트** 보기(통째로 선택·복사)
- 전체 복사, 다시 전사, Finder에서 보기, 삭제(휴지통으로 이동 — 되살릴 수 있음)

- **마이크와 컴퓨터 소리를 따로 저장**: 마이크는 ScreenCaptureKit, 컴퓨터 소리는 Core Audio 프로세스 탭으로 받아 각각 `mic.m4a`, `system.m4a`로 기록 (Mac 전화 앱 통화 소리 포함). Toolbelt 자신의 소리는 제외.
- **저장 위치**: `~/Library/Application Support/Toolbelt/Recordings/<날짜 시각>/` (`mic.m4a`, `system.m4a`, `meta.json`, `transcript.txt`, `transcript-apple.json`). 녹음 창의 "Finder" 버튼으로 연다.
- **자동 전사**: 녹음이 끝나면 자동으로 전사한다 (대기열로 하나씩 순서대로). 앱을 실행할 때 아직 전사 안 된 녹음도 처리한다. 실패하면 자동 재시도 없이 "다시 전사" 버튼.
- **전사 방식**: Apple 기기 내 음성 인식(SpeechAnalyzer, macOS 26, 한국어, 오프라인·무료)으로 두 트랙을 따로 전사해 시간순으로 합친다.
  `[00:12] 나: …` / `[00:15] 상대: …` 형식으로 `transcript.txt`에 저장하고 바로 연다.
- **시간 데이터 보관**: `transcript-apple.json`에 트랙별 결과 구간(start/end)과 단어별 start/end/신뢰도를 저장한다 (시간은 녹음 시작 기준 초).
  나중에 다른 전사 엔진을 쓸 때 문장 재분할·결과 비교에 쓰기 위함. 다른 엔진 결과는 `transcript-<엔진>.json`으로 나란히 둔다.
- 스피커로 들으면 상대 소리가 마이크에도 들어가 "나"에 중복될 수 있다 → 이어폰 권장.
- 녹음 중 앱을 종료하면 파일을 마무리한 뒤 종료한다.

권한 (처음 녹음할 때): **마이크**, **화면 및 시스템 오디오 녹음** (시스템 설정 → 개인정보 보호 및 보안).
화면 녹음 권한은 허용 후 Toolbelt를 다시 실행해야 적용된다.

### 창 배치 (`Sources/Toolbelt/WindowSnap/`)

현재 포커스된 창을 배치한다. Rectangle과 같은 40가지 배치를 지원하고, **메인 창 → 창 배치**에서 종류마다 켜고 끄고 단축키를 지정한다
(단축키 칸 클릭 → 키 입력, ⌫ 지우기, ⎋ 취소). 켠 배치는 팝오버에 아이콘 타일로 나타난다.

- 절반: 왼쪽·오른쪽·위·아래·가운데 / 모서리 4개 / 3분할: 1/3 세 개, 앞·가운데·뒤 2/3 / 4등분: 1/4 네 개, 앞·뒤 3/4 / 6분할 6개
- 크기: 최대화, 거의 최대화(90%), 세로 최대화, 크게·작게(30pt씩), 가운데, 원래대로(처음 배치하기 전으로)
- 이동: 왼쪽·오른쪽·위·아래 가장자리로 (크기 유지) / 디스플레이: 다음·이전 (상대 위치 유지)

기본으로 켜진 배치와 단축키 (Rectangle 기본값, ⌃⌥):

| 배치 | 단축키 | 배치 | 단축키 |
| --- | --- | --- | --- |
| 왼쪽 / 오른쪽 절반 | ⌃⌥← / ⌃⌥→ | 위 / 아래 절반 | ⌃⌥↑ / ⌃⌥↓ |
| 왼쪽 위 / 오른쪽 위 | ⌃⌥U / ⌃⌥I | 왼쪽 아래 / 오른쪽 아래 | ⌃⌥J / ⌃⌥K |
| 1/3 첫·가운데·마지막 | ⌃⌥D / F / G | 앞 2/3 / 뒤 2/3 | ⌃⌥E / ⌃⌥T |
| 최대화 / 세로 최대화 | ⌃⌥↩ / ⌃⌥⇧↑ | 크게 / 작게 | ⌃⌥= / ⌃⌥- |
| 가운데 / 원래대로 | ⌃⌥C / ⌃⌥⌫ | 다음 / 이전 디스플레이 | ⌃⌥⌘→ / ⌃⌥⌘← |

이미 오른쪽 절반에 붙은 창에서 오른쪽 절반을 한 번 더 하면 오른쪽 모니터의 왼쪽 절반으로 넘어간다 (왼쪽은 반대). 그 방향에 모니터가 없으면 그대로.
⌃⌥⌘R(디스플레이 비상 복구)은 창 배치에 지정할 수 없고, 같은 키를 다른 배치에 지정하면 원래 배치에서 빠진다.

### 클립보드 기록 (`Sources/Toolbelt/Clipboard/`)

복사한 **텍스트**를 최근 200개, 7일 동안 기록한다 (기본 꺼짐 — 시작 안내나 메인 창 → 클립보드에서 켠다). 단축키는 없고 팝오버·메인 창에서 누르면 다시 복사된다.

**메인 창 → 클립보드**: 왼쪽 목록(검색, 방향키 이동, 더블클릭 복사, Delete 삭제, 우클릭 메뉴), 오른쪽 상세(전체 내용·출처·시각·글자 수, 비밀 항목은 인증 후 30초 보기),
⚙︎ 설정 시트(기록 켜기, 클립보드 접근 권한, 비밀로 기억한 값, 비밀로 취급할 앱, 모두 지우기).

- 일반 텍스트: 기록에 그대로 (이 Mac에만, 파일은 AES-GCM 암호화, 암호화 키는 **보안 칩(Secure Enclave)** 키에서 만든다)
- **비밀**로 판단되면 값은 "Touch ID/암호가 있어야 쓸 수 있는" 보안 칩 키로 따로 암호화하고, 기록에는 `sk-p••••••Xy4z`처럼 가려서 보여준다.
  다시 복사할 때 **Touch ID / Mac 암호**를 확인하고(보안 칩이 강제) 30초 뒤 클립보드에서 지운다.
- 키체인을 쓰지 않는 이유: 자체 서명 앱은 키체인 항목이 빌드별로 묶여, 업데이트할 때마다 로그인 암호 창이 뜬다.
  - 비밀번호 관리자가 붙이는 민감 표시(`org.nspasteboard.ConcealedType`)가 있을 때
  - 제외 앱(암호, 키체인 접근, 1Password, Bitwarden 등 — 추가·삭제 가능)에서 복사했을 때
  - API 키·토큰·개인 키·비밀번호가 든 주소·무작위 긴 문자열 형식일 때
- 평범한 비밀번호는 구별할 수 없으므로 기록 항목의 🔒 버튼으로 "비밀로 바꾸기". 그 값은 **기억**해서 다음에 복사해도 처음부터 비밀로 저장한다
  (값 대신 보안 칩 키로 만든 HMAC 지문만 보관, 기록이 지워져도 남음, "모두 잊기"로 삭제). 잘못 바꾼 항목은 🔓 "일반으로 바꾸기"(인증 필요).
- `TransientType`/`AutoGeneratedType` 표시가 있으면 기록하지 않는다. 일시정지, 항목 삭제, 모두 지우기.
- macOS 26은 다른 앱의 클립보드를 읽을 때 허용을 묻는다 → 시스템 설정 → 개인정보 보호 및 보안에서 Toolbelt를 **항상 허용**. 상태는 메인 창 → 설정 → 권한(그리고 시작 안내)에서 볼 수 있다.

### 사이트 차단 (`Sources/Toolbelt/SiteBlock/`)

지정한 사이트(기본 youtube.com, youtu.be, instagram.com)를 이 Mac의 모든 브라우저·앱에서 막는다. `/etc/hosts`에 `0.0.0.0`으로 적는 방식 (기본 꺼짐).

- **메인 창 → 사이트 차단**: 끔 / 항상 차단 / 시간표대로, 차단할 사이트 추가·삭제(주소를 붙여 넣으면 도메인만 남김, `www.`·`m.`도 함께 막음), 요일·시간대 시간표(자정 넘김 가능).
- 처음 한 번 **관리자 암호로 도우미를 설치**한다: `/Library/Application Support/Toolbelt/apply-blocklist.sh`(root 소유) + LaunchDaemon `kr.clo3olb.toolbelt.siteblock`.
  앱은 사용자 소유인 `blocked-domains.txt`에 지금 막을 도메인만 적고, 도우미가 파일 변경을 보고 hosts의 Toolbelt 구역을 고친다. 그래서 켜고 끌 때 암호를 묻지 않는다.
  도우미는 도메인 형식만 받아 `0.0.0.0`/`::`으로만 적는다. '도우미 제거…'로 차단 구역과 도우미를 모두 지운다.
- 한계: 브라우저의 보안 DNS(DNS over HTTPS)를 켜면 우회될 수 있고, 시간표는 Toolbelt가 실행 중일 때만 바뀐다.

### 저장 장치 (`Sources/Toolbelt/Storage/`)

연결된 디스크(시동 디스크 + 외장)의 사용·남은·전체 용량. 75% 이상 주황, 90% 이상 빨강. 꽂거나 뽑으면 바로 갱신.
외장 디스크는 꺼내기, 모두 Finder에서 열기. 팝오버 섹션과 메인 창 페이지가 있다.

### 디스플레이 (`Sources/Toolbelt/Display/`)

팝오버 → 디스플레이 → 각 모니터 행의 버튼.

- **연결 해제 / 다시 연결**: 케이블을 꽂은 채 macOS에서 모니터를 뺀 것처럼 처리 (비공개 API `CGSConfigureDisplayEnabled`)
- **주로 설정**: 상대 배치는 유지하고 메뉴바·Dock 기준 화면 변경
- **모든 디스플레이 다시 연결**: ⌃⌥⌘R (비상 복구)

안전장치:

1. 마지막 남은 디스플레이는 연결 해제 불가
2. 연결 해제 후 15초 안에 "유지"를 누르지 않으면 자동 재연결
3. 해제 상태는 세션 한정 — 로그아웃/재부팅하면 원래대로
4. 해제한 모니터는 저장해 두어 앱 재시작 후에도 팝오버/⌃⌥⌘R로 재연결 가능
5. 그래도 안 되면 케이블을 뺐다 꽂기

비공개 API라 macOS 업데이트 후 동작이 바뀔 수 있다.

### 시스템 (`Sources/Toolbelt/SystemStats/`)

팝오버 "시스템" 섹션에 원형 게이지로 표시 (75% 이상 주황, 90% 이상 빨강). 팝오버가 열려 있는 동안만 2초마다 갱신한다 (닫혀 있으면 측정 안 함).

- **CPU**: 전체 코어 평균 사용률
- **메모리**: 활성 상태 보기의 "사용된 메모리"와 같은 기준 (앱 메모리 + 와이어드 + 압축됨)
- **저장 공간**: 시동 디스크, Finder와 같은 기준 (정리 가능한 공간은 남은 공간으로 계산)
- **활성 상태 보기**: 활성 상태 보기 앱 열기
- **온도·팬**: CPU 코어 온도를 **온도계 게이지**로(20~100°C, 70°C 이상 주황, 85°C 이상 빨강), 팬 속도, macOS 발열 상태(보통/약간 높음/높음/위험).
  Apple Silicon에는 온도 공개 API가 없어 SMC(비공개)에서 읽는다 — CPU 온도는 코어 센서 중앙값(M4: `Te0…`+`Tf0…`, M1~M3: `Tp…`+`Te0…`).
  macOS 업데이트로 읽지 못하게 되면 "온도 정보 없음"으로 표시된다.

### 키보드 — Caps Lock 한/영 전환 (`Sources/Toolbelt/InputSwitch/`)

카라비너 없이 Caps Lock 한/영 전환의 지연을 없앤다. 팝오버 → 키보드에서 켜고 끈다 (기본 켜짐).

Caps Lock을 F19로 리매핑하고(`hidutil`과 같은 UserKeyMapping, 드라이버 불필요), macOS 단축키로 전환한다.
누르는 즉시 전환된다. 대문자 고정은 쓰지 않는다 (대문자는 Shift).

**최초 1회 설정**: 시스템 설정 → 키보드 → 키보드 단축키… → 입력 소스 → "이전 입력 소스 선택"을 더블클릭하고
Caps Lock을 누르면 F19로 지정된다. 지정되지 않았으면 팝오버에 안내가 뜬다.

리매핑은 세션 한정이라 Toolbelt가 실행될 때마다 적용하고, 종료(팝오버 → 종료)하면 Caps Lock이 원래대로 돌아온다.

## 개발: 빌드 / 설치

```bash
make install   # 빌드 → /Applications/Toolbelt.app 설치 → 실행
make run       # build/ 에서 바로 실행
make icon      # Scripts/make-icon.swift로 Resources/AppIcon.icns 재생성
make release   # 배포용 build/Toolbelt-<버전>.zip (Toolbelt Signing 서명 필수) — docs/DISTRIBUTION.md
make publish NOTES=docs/releases/<버전>.md   # zip·EdDSA 서명·appcast → GitHub Release (DRY_RUN=1로 미리 보기)
make clean
```

Xcode 없이 Command Line Tools만으로 빌드된다.

## 권한

창 배치에 **손쉬운 사용** 권한이 필요하다.
시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → Toolbelt 허용.

기본 서명은 키체인의 자체 서명 인증서 `Toolbelt Signing`이다 (키체인 접근 → 인증서 지원 → 인증서 생성, 유형 "코드 서명").
서명이 고정돼 재빌드해도 권한이 유지된다. 인증서를 새로 만들면 권한을 한 번 다시 줘야 한다.
인증서가 없으면 `make install SIGN_ID=-`(ad-hoc). ad-hoc은 빌드마다 서명이 바뀌어 재설치 후 권한이 풀릴 수 있으니,
그럴 땐 목록에서 Toolbelt를 `-`로 지운 뒤 다시 추가한다.

## 로그인 시 자동 실행

메인 창 → 설정 → **로그인 시 자동 실행** 스위치 (`SMAppService`, `Sources/Toolbelt/LoginItem/`).
처음 켤 때 macOS가 "로그인 항목 추가됨" 알림을 띄울 수 있다. 승인이 필요하면 "(설정에서 승인 필요)"로 표시된다.

수동으로 하려면: 시스템 설정 → 일반 → 로그인 항목 → `+` → `/Applications/Toolbelt.app`.
